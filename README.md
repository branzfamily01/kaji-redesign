# 家事リデザイン v2

「今日、誰が何をするか」を一瞥できる家庭運営ボードと、家事を減らすための裏側の改善機能を分離したPWAです。

## v2
- 人ごと / 時間ごとの今日ボード
- 共同タスクと担当者別の完了
- 五十音順 / 登録順
- 表示フォント切替
- 家庭タスク棚卸しテンプレート
- 週次 / 月次 / 単発スケジュール
- 子ども専用「今日やること」画面
- 自立レベルの成長履歴
- 月次の改善・成長表示
- APIなしのAI改善相談文コピー
- `.ics` カレンダー書き出し
- JSONバックアップ / 復元
- PWA / オフライン対応

## 保留
- 家族複数端末のリアルタイム同期（バックエンドが必要）
- アプリ終了後も確実に届く自動通知（Push基盤が必要）
- 買い物・在庫を独立アプリ級に拡張すること（肥大化を避ける）

GitHub Pagesではリポジトリ直下を公開してください。公開起点は `index.html` です。
