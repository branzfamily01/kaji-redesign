# 家事リデザイン

家庭内のタスクを「今日、誰が何をするか」で一瞥できるようにしつつ、裏側で **やめる / 自動化 / 簡略化 / 分担 / 子どもの自立移管** を進める静的Webアプリです。

## v1.1

- タスク一覧を **五十音順 / 登録順** で切り替え
- 設定画面から **表示フォントを変更**
- 1つのタスクに **複数人を担当設定** して共同タスクとして扱える
- 旧データの `owner` 形式は起動時に自動で複数担当形式へ移行
- 共同タスクはホームの各担当者欄に表示し、完了状態はタスク単位で共有
- PWAキャッシュを v1.1 に更新

## 公開

GitHub Pages ではリポジトリ直下をそのまま公開します。公開起点は `index.html` です。

## データ

- アカウント不要
- `localStorage` に端末内保存
- 設定画面から JSON バックアップ / 復元
- PWA 対応
